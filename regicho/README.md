# マルシェ レジ帳

マルシェ出店者のための、かんたん会計・テストマーケティング記録アプリです。

- スマホのブラウザだけで使えます（アプリのインストールやログインは不要）
- 商品を種類ごとに色分けして表示します
- 合計・おつりの計算、お客様の人数・どんな方・年代・来店（初めて／リピーター）・ひとことを記録できます
- 記録はそのスマホの中だけに残ります。マルシェが終わったら「CSVで保存」で持ち出してください
- はじめて開くと見本の商品が入っています。「見本を消して、自分の商品を入れる」で自分のお店用に切りかえられます

## 公開のしかた（GitHub Pages）

1. このフォルダの中身（index.html / sw.js / manifest.webmanifest / icon.svg）をリポジトリに置きます
2. リポジトリの Settings → Pages で、公開するブランチとフォルダを選びます
3. 表示されたURLをスマホで開きます
